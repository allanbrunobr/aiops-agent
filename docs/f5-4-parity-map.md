### 1.5 Wiring plan (4b)

1. **Capture structured data in the nodes** (write-set: `blueprint/adapters/safety_nodes.py`,
   `blueprint/adapters/pipeline_nodes.py`): pre-validator and version-validator store their full
   result dicts (e.g. `metadata["_safety_validation"]`, `metadata["_remediation_validation"]`);
   diagnoser/fallback store `pattern_matched` and a verification dict; nodes append timeline entries.

   `application/use_cases/postmortem.py` or a new `blueprint/adapters/state_adapter.py`) building
   the V0-shaped `result` dict from state + metadata. Reconstruct `MitigationAction` from
   `state.proposed_action` for `stages.mitigation.action`.
3. **Replace the template** in `make_postmortem_node` (`blueprint/adapters/pipeline_nodes.py:240-278`)
   with `render_postmortem_markdown(state_to_result(state), metadata["_incident"], now=datetime.now(), tracker_url=..., tracker_issue_key=...)`.
   Fallback (`:283`) inherits automatically. `_state_after_abort` (`v1_runner.py:60-64`) inherits too.
4. Keep `save_postmortem_v1` for markdown; JSON output (4c) uses `serialize_result` + `json_default`.

### 4.1 How `tests/conftest.py::_run_pipeline` works (`:242-378`)

Manual mirror of V0 (docstring: "Espelha a sequência de main.main() sem CLI parsing nem rich
output"), `--no-llm --no-rag` semantics, stdout/stderr redirected. Sequence:
1. `TelemetrySanitizer(strict_mode=False).sanitize_all(...)` mutates incident in-place (`:265-273`).
2. `Aggregator().process(...)` (`:277`); `ContextCompressor(compression_level="balanced").compress(report)` (`:281`).
3. Agents with **default constructors** (no config): `DetectionAgent()`, `DiagnosisAgent(max_iterations=1)`, `MitigationAgent()`, `TNRSafetyGuard()` (`:284-287`).
4. Timeline via local `_rec` closure (`:293-301`); `result = {"success": False, "stages": {}}`.
5. `detector.detect(report)` → `stages.detection`; `diagnoser.diagnose(report, None)` → `stages.diagnosis`;
   **`mitigator.propose(diagnosis)`** → `stages.mitigation`; `mitigator.verify_with_tnr(...)` → `stages.verification` (`:305-345`).
6. `PreExecutionValidator(auto_approve_low_risk=True, max_blast_radius=3, require_rollback_plan=True)` → `stages.safety_validation` (`:348-362`).
7. `VersionValidator().validate_mitigation_action(action)` → `stages.remediation_validation` (`:364-373`).
8. `result["scenario_name"]` if given (`:375-376`).
